# Skill Selection Profiles

The full plugin stays below the conservative Codex discovery-budget gate, but most repositories benefit from a smaller active skill surface.

Profiles are advisory sets:

- `core.json` — control architecture, contracts, context, harnesses, loops, graphs, multi-agent, evals, security, learning, and verification;
- `lifecycle.json` — product discovery through retirement plus authentic use and Product Fitness;
- `rust.json` — agentic Rust architecture, runtime, durability, protocols, observability, and verification;
- `ultragoal.json` — explicit advisory specialists for co-installation while Harness UltraGoal remains the sole implicit front door;
- `full.json` — every skill.

No Agentic Engineering profile enables implicit invocation. Each declares Harness UltraGoal as the external sole first-entry gateway; specialists remain explicit so one front door owns routing. Use `scripts/render_profile_config.py` to emit `[[skills.config]]` entries for a selected profile; review the output before adding it to Codex configuration.
