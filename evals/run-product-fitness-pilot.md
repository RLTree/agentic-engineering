# Run Product Fitness Pilot

Freeze one candidate and exercise representative work through the public product surface.

Run a read-only Field Pulse and complete Product Journey Reviews across success, validation, permission, failure, interruption, diagnosis, recovery, preserved unrelated state, and repeated-use paths. Record exact identities, time to verified value, human interventions, review rounds, correction effort, accessibility, risk, and evidence quality.

Agent-use, expert human use, representative human use, and repeated use remain distinct. Return advance, hold, narrow, revert, stop, redesign, or gather-more-evidence with an explicit claim ceiling.
