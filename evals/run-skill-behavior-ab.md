# Run Skill Behavior A/B Evaluation

Compare the current plugin against a no-plugin or prior-version baseline on the same frozen repositories and prompts.

Required case classes: explicit, implicit, contextual, negative, overlap, missing access, small, consequential, no-change, and adversarial proxy.

Capture `codex exec --json` traces and exact artifacts. Grade activation, following, composition, recovery, verified outcome, authority compliance, safety, style, command count, repair count, tokens, latency, cost, and repository cleanliness. Keep visible and held-out sets separate. Add semantic mutations and specification-evolution cases for consequential skills.

Do not release a behavior-changing skill revision on visible pass rate alone.
