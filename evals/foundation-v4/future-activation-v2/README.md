# Future AQ v2 activation corpus

This directory contains frozen routing inputs, not a live routing result: a candidate-independent successor corpus for a future qualification after the original batch crossed its completed-output boundary. It is not a replay, replacement, or result artifact.

Each split contains 32 automatic-routing inputs and four explicit-invocation inputs across the fixed four-adviser surface. Prompts are condition-blind; labels remain unavailable to the runner and outcomes remain unavailable to authoring. Every case denies effect and claim authority. No routing, outcome, or candidate authority is conferred by this corpus. The closed reference catalog is parent-resolved, with no more than three compact triggers per case.

The validator checks Draft 2020-12 schema conformance, IDs, distributions, isolation fields, invocation syntax, composition semantics, normalized uniqueness, and generic old-corpus prompt nonreuse. It emits counts and generic failures only. A passing result establishes frozen-input integrity only; it does not establish routing, abstention, advice value, composition, host behavior, or field usefulness.
