# Foundation V4 activation corpus

AQ1 and AQ2 remain frozen historical no-replay lineage. The frozen `future-activation-v3` AQ3 corpus is the current future input; it confers no qualification, routing, outcome, or candidate authority.

This root contains frozen routing inputs, not a live routing result. Each split has 32 automatic cases and four separate explicit-invocation cases. Qualification consumes the 32 heldout automatic cases plus all eight explicit cases: exactly 40 cases per condition and 80 strictly alternating presentations. Both conditions intentionally exercise the same fixed four-adviser surface (`agentic-engineering`, `codex-task-contract`, `verification-strategy-engineering`, and `engineering-learning-loop`); the current package condition is not an unrestricted 30-skill routing comparison. `activation-authoring.json` supports hypothesis formation. `activation-heldout.json` is co-located in the repository to freeze integrity, not to provide secrecy, and must never tune a routing change.

Both corpora are candidate-independent: a future run contract must prove parity of task text, model, reasoning setting, tools, and host surface for the current package and the reduced four-skill candidate. The evaluator must mount prompt-only views and withhold outcomes; this structural corpus validator cannot prove that blinding. The parent resolves the closed semantic reference triggers; advisers do not select their own reference payload. A trigger allows only compact task-relevant material and never authorizes loading a full schema or template merely because a case exists.

Every case is condition-blind and grants no effect or claim authority. Hidden labels stay out of the runner context, and outcome data stays out of authoring custody. Raw model trajectories, per-run receipts, and temporary scoring files are ephemeral and are not persisted here. A completed poor run is scored rather than content-retried; only an infrastructure failure before completion may retry once, with its reason held in the external run index. Two materially similar failures require a changed hypothesis or a stop.

The validator establishes frozen-input integrity only: corpus shape, distributions, isolation, and absence of legacy prompt reuse. It does not establish live activation, abstention, adviser value, composition, host behavior, or field usefulness.
