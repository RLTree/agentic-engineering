# AQ4 future activation corpus v4

This directory contains future-input corpus material only. The author did not see the candidate selector, scorer, checker, runner, prior corpus, aggregate outcomes, case outcomes, or raw results.

Each case is a condition-blind, proposal-only routing specification. A case may select zero, one, or two decision atoms. An exact canonical invocation is required only for explicit cases; bare text never invokes an adviser. Ambiguity defaults to no selection. The labels prohibit authority assignment, effects, policy adoption, and completion, efficacy, or product claims.

Reference expectations use only compact references from the reduced candidate metadata. Resolution is deterministic minimum cover: for every owner/trigger pair, select one eligible compact reference; if equally minimal choices cover the same pair, choose the lexicographically first payload identifier. No full schema or template is expected.

This corpus is frozen before any run. Do not replay it after any results are observed. Persist aggregate-only reporting; do not retain raw prompts, case outputs, or other raw evaluation material. Validation may establish structural conformance only; it does not establish selector quality, runtime behavior, efficacy, product behavior, or release readiness.
The evaluator enforces `full_schema_or_template_expected: false` for every case; it is a machine-readable closed label, not narrative guidance.
