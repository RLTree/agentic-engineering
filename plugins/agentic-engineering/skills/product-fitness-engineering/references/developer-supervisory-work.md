# Developer Supervisory Work

Agentic development shifts effort from production to direction, evaluation, correction, and integration. Measure this work rather than treating generated code volume as productivity.

Capture:

- task framing and context preparation time;
- agent monitoring and interruption frequency;
- review and correction time;
- context switching and cognitive load;
- time to verified value;
- rework, recovery, and trust calibration;
- retained understanding and ownership;
- effect on flow, job satisfaction, and burnout risk.

Use multiple measures. Self-reported productivity, commits, lines, tokens, or PR counts can each move in the opposite direction from product or team outcomes.

Evidence basis: R144, R145, R146, R131.
