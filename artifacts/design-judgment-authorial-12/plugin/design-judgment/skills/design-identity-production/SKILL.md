# Identity Production

Preserve the approved concept while turning it into canonical production truth.

- Use editable vector sources as authority; raster previews never become the source of truth.
- Define primary, compact, mark-only, monochrome, reversed, and small-size variants only when the system needs them.
- Test reduction, stroke behavior, spacing, clear space, contrast, and realistic light/dark contexts.
- Keep names, IDs, filenames, queue records, previews, status, counts, and manifest derived atomically from the same reversible records. Independent counters or regenerated IDs are prohibited.
- Distinguish locked brand assets from generated production variants.
- Package exact source files, exports, color values, type information, minimum-size guidance, and replacement notes for synthetic material.
- Preflight claims must be calculated from the actual assets. Never display a passing contrast, size, or format status from hard-coded text.
- Narrow and keyboard paths must still support inspection, queue changes, undo, and manifest review.

The presentation surface should make the system easy to judge, but specimen polish cannot substitute for complete production files.
